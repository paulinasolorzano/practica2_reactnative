Práctica 2

Navegación entre pantallas · React Navigation Stack

Explore Mich — Catálogo turístico de Michoacán
🎯 Objetivo

Implementar navegación entre la pantalla de catálogo y una pantalla de detalle utilizando React Navigation con Stack Navigator. Al presionar el botón "Ver más" en cada tarjeta, el usuario navega a una nueva pantalla con información del lugar seleccionado.

📦 Instalación de dependencias
⚠️ Usar siempre --legacy-peer-deps debido a conflictos de versiones con @rneui/base@5.0.0
npm install react-native-screens react-native-safe-area-context @react-navigation/native @react-navigation/native-stack --legacy-peer-deps

📝 Archivos modificados
index.js — actualizado

Se agregó enableScreens() para compatibilidad con react-native-screens:

import { enableScreens } from 'react-native-screens';
enableScreens();

import { registerRootComponent } from 'expo';
import App from './App';

registerRootComponent(App);
App.js — actualizado

Se configuró el Stack Navigator con dos pantallas registradas:

import React from 'react';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import CatalogScreen from './screens/CatalogScreen';
import DetailScreen from './screens/DetailScreen';

const Stack = createNativeStackNavigator();

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator
        initialRouteName="Catalog"
        screenOptions={{
          headerStyle: { backgroundColor: '#00796b' },
          headerTintColor: '#fff',
        }}
      >
        <Stack.Screen name="Catalog" component={CatalogScreen} />
        <Stack.Screen name="Detail" component={DetailScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}
components/PlaceCard.js — actualizado

Se agregó useNavigation() y el evento onPress al botón "Ver más":

import { useNavigation } from '@react-navigation/native';

export default function PlaceCard({ place }) {
  const navigation = useNavigation();

  return (
    <Card>
      ...
      <Button
        title="Ver más"
        icon={<Icon name="map" type="feather" color="white" size={18} />}
        buttonStyle={styles.button}
        onPress={() => navigation.navigate('Detail', { place })}
      />
    </Card>
  );
}
screens/DetailScreen.js — NUEVO

Pantalla de detalle que recibe el lugar seleccionado por route.params:

import React from 'react';
import { View, Text, Image, ScrollView, StyleSheet } from 'react-native';

export default function DetailScreen({ route }) {
  const { place } = route.params;

  return (
    <ScrollView style={styles.container}>
      <Image source={{ uri: place.image }} style={styles.image} />
      <View style={styles.content}>
        <Text style={styles.category}>{place.category}</Text>
        <Text style={styles.title}>{place.name}</Text>
        <Text style={styles.description}>{place.description}</Text>
      </View>
    </ScrollView>
  );
}
✅ Resultado esperado
  • La pantalla principal muestra el catálogo de lugares con tarjetas
  • Al presionar "Ver más" navega a la pantalla de detalle del lugar
  • La pantalla de detalle muestra imagen, categoría, nombre y descripción
  • El header muestra el nombre del lugar y un botón de regreso automático
🔑 Conceptos clave
ConceptoDescripción
Stack NavigatorNavegación tipo pila — cada pantalla se apila sobre la anterior
NavigationContainerComponente raíz que habilita la navegación en toda la app
useNavigation()Hook para acceder al objeto de navegación desde cualquier componente
route.paramsObjeto que contiene los datos enviados entre pantallas
--legacy-peer-depsFlag de npm para resolver conflictos de versiones entre dependencias
npx expo start --clearLimpia el caché de Metro Bundler al encontrar errores extraños
